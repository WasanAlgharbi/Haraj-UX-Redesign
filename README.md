# Haraj HCI Redesign

### Human-Computer Interaction (HCI) Team Project

**College of Computer Science and Engineering**  
**University of Ha'il**

---

## Project Overview

This project presents a user-centered redesign of the Haraj mobile application as part of the Human-Computer Interaction (HCI) course.

The redesign process involved identifying usability issues through user research, analyzing user feedback, creating low-fidelity sketches, and developing high-fidelity interface solutions using Figma.

The project focuses on improving usability, navigation, communication, and the overall user experience.

---

## Project Objectives

- Analyze the usability of the Haraj application.
- Conduct user interviews and questionnaires.
- Identify major user pain points.
- Create low-fidelity wireframes.
- Design high-fidelity user interfaces.
- Apply Human-Computer Interaction principles to improve usability.

## Design Process

The redesign followed the User-Centered Design (UCD) process:

1. User Research
2. Interviews
3. Questionnaire
4. Problem Analysis
5. Low-Fidelity Sketches
6. High-Fidelity Interface Design
7. Prototype Evaluation
